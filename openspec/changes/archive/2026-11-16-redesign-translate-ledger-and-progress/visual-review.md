## Deviations from the design document found during review

- Group "Remove" needed a wider action column than the mockup's 44 px for the text button; the row "✕" shares that column.
- The status line wraps rather than truncating at narrow widths, and once the run has finished it reads "Every file has been handled." instead of naming the last file.
- In the mono rows, Chromium renders some bracket glyphs of the sample names with a slight tint (font fallback); worth a glance in the desktop app.
