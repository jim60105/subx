## 2. Generation pipeline

**Ordering matters in this group.** The stock digests must be captured before the
stock files are overwritten (2.1), and `icons:check` must not join `verify` until
the record it reads exists (2.7 after 2.6). Do not run `npm run verify` or push
between 2.2 and 2.7.

- [x] 2.1 **Before anything overwrites the icons**, capture the SHA-256 of every currently committed file under `src-tauri/icons/` (`git ls-files src-tauri/icons | xargs sha256sum`) and write them into `scripts/app-icon.stock-digests.json` as the fixture task 3.6 asserts against. Once 2.6 has run, these values are no longer recoverable from `HEAD`.
- [x] 2.2 Add `scripts/generate-icons.mjs`: run `tauri icon assets/brand/subx-icon.svg -o src-tauri/icons`; run `tauri icon assets/brand/subx-icon-macos.svg` into a temp directory, assert the resulting `icon.icns` exists and is non-empty — **throwing if it is not, rather than leaving the master's full-bleed icns in place** — and copy it over the first pass's; remove the generated `android/` and `ios/` trees by the specific subpaths `tauri icon` emits rather than deleting those directories wholesale; then write the generation record. Keep the record-writing and the icns-guard logic in separately exported functions so both can be tested without invoking the Tauri CLI.
- [x] 2.3 Define the generation record `src-tauri/icons/.icon-source.json`: the SHA-256 of each source SVG, plus which source each output slot was produced from (`icon.icns` → the macOS source, everything else → the master). One file serves both the staleness gate and the macOS attribution scenario.
- [x] 2.4 Add `scripts/check-icon-source.mjs`: recompute each source SVG's digest, compare against the record, exit non-zero naming any file that drifted or is missing from the record.
- [x] 2.5 Remove the empty `src-tauri/icons/android/` and `src-tauri/icons/ios/` directory shells left by an earlier `tauri icon` run.
- [x] 2.6 Add the `icons:generate` script to `package.json`, run it, and commit the regenerated set together with the sources and the generation record — sources and outputs must land in one commit, or the tree sits in a state the new gate rejects.
- [x] 2.7 Add `icons:check` to `package.json` and to the `verify` chain. This comes after 2.6 so `verify` never runs against a missing record.
- [x] 2.8 Add `64x64.png` to `bundle.icon` in `src-tauri/tauri.conf.json` (design.md D4). This is the only edit to that file.

- [x] 3.3 Cover the palette scenarios. `…#the-backplate-gradient-is-the-token-gradient` — resolve `--accent-gradient-strong` out of `src/styles/tokens.css` and assert its two colour values are exactly the master's two gradient stops. **The declaration is `linear-gradient(135deg, #c64916, var(--accent-to))`: one literal and one `var()` that must be followed to `--accent-to`'s own declaration. A single regex over that one line finds only half the pair** (design.md D6). `…#the-foreground-clears-wcag-aa-against-every-point-of-the-plate` — compute white against both stops from the file and assert ≥ 4.5:1 (expected 4.81:1 and 5.56:1). `…#the-tile-is-distinguishable-from-the-surfaces-it-sits-on` — assert ≥ 3:1 against `#141518` and `#f9f8f6` (expected 3.28:1 and 5.24:1).
