## [0.1.0] - 2026-07-29

### Added
- Initial release of SubX desktop GUI application for `subx-cli`.
- Subtitle matching wizard with drag-and-drop video and subtitle file pairing.
- Batch format conversion wizard supporting SRT, ASS, VTT, and SUB formats.
- Settings panel with AI provider configuration (OpenAI, OpenRouter, Azure OpenAI, local LLMs) and connection testing.
- Custom frameless titlebar with window management controls and system theme integration.
